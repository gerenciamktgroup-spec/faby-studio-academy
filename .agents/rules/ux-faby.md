# Visual & UX Standards - Fabi Studio Academy

## Brand & UI Identity
1. **Public Web Portal**:
   - High emotional impact, luxury beauty academy aesthetic.
   - Core Colors: Primary Fabi Pink (`#E91E63`), Vibrant Fuchsia (`#C2185B`), Luxury Charcoal (`#121212`), Warm Cream/White (`#FFFDFB`), Soft Rose Accent (`#FDF2F8`).
   - Typography: Elegant modern headings (Outfit / Inter / Playfair), clean body text.
   - Highlights: Transformation showcases, course preview videos, student certificates, real tutor community highlights.

2. **Campus Experience (Alumna, Tutor, Auditor, Admin)**:
   - Clean, functional, high-efficiency LMS layout.
   - Controlled pink usage (navigation highlights, progress bars, active states, key CTAs).
   - High accessibility contrast, glassmorphic cards, clear progress widgets, active learning indicator badge.
   - Distinct role portals with customized navigation sidebars.
