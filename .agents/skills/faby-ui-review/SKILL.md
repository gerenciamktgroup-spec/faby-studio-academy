# Fabi UI Review Skill

## UI Criteria
1. Public portal: Premium beauty brand aesthetics (`#E91E63`, `#C2185B`, `#121212`, `#FFFDFB`).
2. Campus portal: Functional EdTech design with controlled pink highlights.
3. Accessibility: High color contrast, visible focus outlines, screen-reader friendly labels.
4. Active learning widget: Displays live active training time vs total session time.
