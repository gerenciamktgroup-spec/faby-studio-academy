# FABY STUDIO ACADEMY — Client Demo Guide

## Quick Start
1. Ensure node environment is active.
2. Run `npm run dev` to launch the application at `http://localhost:3000`.
3. Open `http://localhost:3000/demo` to access the Role Switcher.

## Key Presenter Routes
- **Public Brand Homepage**: `http://localhost:3000/`
- **Flagship Lash Course**: `http://localhost:3000/cursos/extensiones-de-pestanas`
- **Demo Checkout Sandbox**: `http://localhost:3000/checkout`
- **Student Onboarding Tour**: `http://localhost:3000/campus/onboarding`
